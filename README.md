# 📌 Overview

ATS Resume Analyzer is an AI-powered application that evaluates resumes against job descriptions using Google's Gemini AI model.

The system helps candidates:
- Measure ATS compatibility
- Identify missing keywords
- Analyze skill gaps
- Improve resume quality
- Optimize resumes for placements and recruitment

---

# ✨ Features

## 📄 Resume Upload
Upload resumes in PDF format for instant analysis.

## 🤖 AI Resume Evaluation
Get professional HR-style feedback on resume quality.

## 📊 ATS Match Percentage
Calculate resume compatibility with job descriptions.

## 🔍 Missing Keyword Detection
Identify important missing technical keywords.

## 🧠 Skill Gap Analysis
Analyze strengths and weaknesses in the candidate profile.

## ⚡ Real-Time Processing
Fast AI-powered analysis using Gemini API.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/ats-resume-analyzer.git
```

---

## 2️⃣ Move to Project Folder

```bash
cd ats-resume-analyzer
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Create `.env` File

```env
GOOGLE_API_KEY=your_api_key_here
```

---

## 5️⃣ Run Application

```bash
python -m streamlit run app.py
```
